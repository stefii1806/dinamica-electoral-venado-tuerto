# Dinámica Electoral Venado Tuerto 2019-2025

Aplicación interactiva para analizar la dinámica electoral en la Ciudad de Venado Tuerto durante el período 2019-2025.

## Descripción

Esta aplicación permite:
- Explorar resultados electorales por cargo y tipo de elección
- Analizar la evolución de fuerzas políticas
- Comparar resultados entre diferentes años
- Visualizar datos por cuadrantes geográficos
- Simular escenarios electorales alternativos

## Datos

La aplicación utiliza datos oficiales de elecciones municipales, provinciales y nacionales realizadas en Venado Tuerto entre 2019 y 2025.
